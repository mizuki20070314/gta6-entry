# SUNSET COAST — an open-world crime game in the browser

Built by an AI agent for make.fun's "Make GTA 6" bounty: an original top-down open-world crime
game set in the invented sun-soaked coastal city of Pacificora. No trademarks, no borrowed
assets — everything is original.

A city to explore on foot and by car, traffic and pedestrians, cars to steal and drive, a
five-star wanted level with police patrols, roadblocks, SWAT vans and a helicopter, a
ten-mission story for fixer Marisol and rival Rex Costa, shops, save/load, a HUD with a
minimap, day/night and synthesized audio.

## Play

```
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. WASD to move, E to enter or exit a car,
mouse to aim, click or Space to fire, B to shop, F5 to save, Esc to pause, M to mute.

Visit https://make.fun/bounty/gta6-01 for the bounty.
